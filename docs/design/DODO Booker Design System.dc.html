Responsive Strategy

No page is built at a fixed pixel width. Web and mobile stay two intentional compositions (per the references), but each is fluid within its own device class — grids use auto-fit/minmax, type and spacing use clamp(), and rows wrap instead of overflowing.

Mobile · 320–599px
Single column, full-width cards, bottom tab nav, fluid clamp() type.
Tablet · 600–1023px
Web composition begins; grids collapse to 2 columns via auto-fit.
Desktop · 1024px+
Full web layout per reference; max-width container, generous gutters.
